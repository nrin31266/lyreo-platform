module boundaries or switch Hibernate schema mutation on as a shortcut.

### 3.6 PostgreSQL job crash/recovery integration

The SQL/worker foundation is present but crash semantics need an integration run with real PostgreSQL:

1. create a Lesson build -> confirm `202 + jobId`;
2. observe `QUEUED -> RUNNING` and persisted steps;
3. request cancel and verify durable `CANCEL_REQUESTED -> CANCELLED`;
4. kill Core while a worker holds a lease;
5. restart/wait lease expiry;
6. confirm another worker recovers the job and fencing prevents stale-worker completion;
7. rerun a completed step and confirm idempotent skip/reuse behavior.
